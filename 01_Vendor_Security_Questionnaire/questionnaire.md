# Vendor Security Assessment Questionnaire

**Overview**
This questionnaire is designed to evaluate the security posture, data protection practices, and compliance controls of third-party vendors seeking to provide services or access internal systems.

---

## 1. Access Control

* **1.1 Multi-Factor Authentication:** *Do you enforce Multi-Factor Authentication (MFA) for administrative database access containing patient dental records?* *(Yes / No / Comments)*
* **1.2 Principle of Least Privilege:** *Is access provisioned based on the Principle of Least Privilege, restricting staff roles to required fields (e.g., daily charting)?* *(Yes / No / Comments)*

---

## 2. Data Protection

* **2.1 Data Encryption at Rest:** *Is all patient electronic protected health information encrypted at rest using AES-256?* *(Yes / No / Comments)*
* **2.2 Data Encryption in Transit:** *Is HTTPS enforced across all patient portal web traffic?* *(Yes / No / Comments)*

---

## 3. Compliance & Governance

* **3.1 Third-Party Audits:** *Has the vendor completed a HIPAA compliance assessment?* *(Yes / No / Comments)*
* **3.2 Incident Response Plan:** *Does a documented data breach response plan exist for handling ePHI leaks?* *(Yes / No / Comments)*

---

## 4. GRC Recommendation & Decision

* **4.1 Risk Assessment Summary:** *Provide an overall risk tier and justification based on identified controls and gaps.* *(Specify Tier & Notes)*
* **4.2 Onboarding Decision:** *Indicate final status (e.g., Pending for onboarding) and required remediation steps.* *(Status / Action Items)*
